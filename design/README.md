# Design — find_me_in_wood

UI source of truth: `.pen` files generated by `tools/gen_pen.py`, which drives the
pen.dev headless editor (`pen interactive`) over its MCP tools. No Claude/Anthropic
involved — the script IS the design agent.

## Layout

- `ui-design-brief.md` — tokens, status-chip language, screen inventory (read first)
- `stitch-prompts.md` — alternative path: paste prompts at stitch.withgoogle.com
- `s1-*.pen` … `s11-*.pen` — one editable canvas per screen, dark theme (default)
- `s1-*-light.pen` … `s11-*-light.pen` — light theme variants
- `s5-map.pen` / `s5-map-light.pen` — contain three frames each: OSM / Google /
  Satellite tile-source variants (FR-6.5); settings picker lives in s7
- `exports/<screen>/<hash>.png` — rendered previews
- `tools/gen_pen.py` — generator: THEMES dicts (dark/light) + tile palettes +
  component helpers + 8 screen builders

## Regenerate

```
python3 tools/gen_pen.py                # all screens, dark + light
python3 tools/gen_pen.py s5-map         # one screen, both themes
```

Requires the `pen` wrapper (`docker/pen-cli/pen` → installed at /usr/local/bin) and an
authenticated session (`pen login` once).

## Conventions

- Canvas 360x800 (logical px, 1080x2400 @3x)
- Tokens in `gen_pen.py` header mirror `ui-design-brief.md`; change them there only
- Every screen carries fix + link chips (constitution P4); bottom nav on Map/Members/
  Networks screens; monospace for keys, coords, counters
